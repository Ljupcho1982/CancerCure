# Јев Мејл-Тријаж

Брз „System 1“ тријаж на мејлови: категорија, акција, сигурност и причина за секој мејл. Под прагот на сигурност (`JEV_THRESHOLD`, по default 80) мејлот оди „за човек“. Брисењето секогаш бара човек. Јев само предлага, не брише и не праќа.

```
cd jev-triage
ANTHROPIC_API_KEY=... GMAIL_ACCESS_TOKEN=... node server.js   # http://localhost:3000
node --test
```

- `ANTHROPIC_API_KEY` е задолжителен. Нема симулација ни резервни правила: без клуч или при грешка од API се враќа грешка.
- `GMAIL_ACCESS_TOKEN` (scope `gmail.readonly`) овозможува вчитување непрочитани мејлови.
- Поправките (`feedback.json`) се враќаат во промптот како примери.
- `JEV_MODEL` го менува моделот (default `claude-haiku-4-5-20251001`).

Без зависности, потребен е Node 18+.
